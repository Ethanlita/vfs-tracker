# 管理限速配置部分保存恢复（#119）

管理页只提交与已确认服务端快照不同的字段。SSM 服务等待本轮全部写入完成，并按字段返回成功或失败结果；单项失败不再让仍在途的其他写入脱离页面控制。

出现部分成功时，页面明确列出已保存项与失败项，并立即重新读取 SSM。读取成功后，已确认的实际值成为新的重置基线，失败字段继续保留管理员尚未保存的草稿并显示字段错误；重试只写失败且仍有差异的字段。若核对读取也失败，页面会锁定表单和保存操作，直到管理员使用独立的“重新核对服务端状态”入口恢复，避免在状态未知时继续覆盖配置。
