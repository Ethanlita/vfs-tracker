# 管理后台读取重试（#114）

系统概览的“重试”现在直接重新调用统计读取，不再执行整页刷新。因此未勾选“记住凭证”的管理员仍保留当前内存会话，错误清除后可在原路由继续工作。同步读取锁阻止快速重复点击产生并行统计请求。

用户、事件和嗓音测试列表在每次完整读取前清除旧错误，成功后显示最新响应。加载下一页使用独立错误状态：失败时保留已显示记录与分页游标，按钮变为“重试加载更多”；成功后追加新记录并清除分页错误。完整读取或筛选失败仍显示明确错误，避免把旧筛选结果冒充成新结果。
