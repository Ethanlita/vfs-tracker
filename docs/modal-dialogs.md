# 详情弹层交互

事件详情和公开用户档案共享 `ModalDialog`（#149），以原生 `dialog.showModal()` 创建模态顶层，portal挂到body，避免祖先动画/transform限制遮罩。背景使用半透明原生backdrop，内容按屏幕尺寸滚动。

- 打开后聚焦有名称的关闭按钮；正反Tab在可操作控件首尾循环，背景由原生模态隔离。
- Escape、关闭按钮和面板外遮罩点击走同一个关闭回调。面板内部点击不关闭。
- 关闭后恢复原入口焦点。入口因删除消失时，将焦点移到主内容；页面滚动状态恢复原值。
- 分页加载可能禁用或移除当前控件。弹层监听这些内容变化，如果焦点已离开弹层，则回到稳定的关闭按钮。
- 请求状态与弹层状态保持独立；删除锁和响应归属规则见[事件删除说明](event-deletion.md)。

## 验证范围

单元测试只模拟jsdom缺失的dialog开关方法，不声称证明浏览器原生背景隔离。共享层测试覆盖焦点进入/恢复、滚动恢复、取消/遮罩和动态内容移除；事件删除与公开档案分页测试验证调用方行为。

真实浏览器验证使用隔离合成账户和21位用户、每位21条事件，覆盖两页用户与两页明细，不读取真实资料。实体手机触摸和屏幕阅读器尚未人工验收。
