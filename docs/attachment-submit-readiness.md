# 附件就绪后提交事件（#159）

SecureFileUpload 通过 onStatusChange 报告 uploading / error / idle。申请上传地址、文件 PUT 和获取访问地址均属于在途状态，直到附件完成回调后才解除阻塞。EventForm 用同步 ref 防止回车、requestSubmit 和重试路径绕过，同时禁用提交按钮并显示等待提示。

上传失败后保留附件重试入口并继续阻止事件提交。用户可以明确选择“放弃此附件”，清除失败状态后提交已有内容。验证错误同样需要修正、重新选择或放弃，不会默默遗漏已选择文件。事件提交期间禁用新的文件选择和上传重试，避免请求快照形成后再追加附件。

37项相关测试通过：三个上传阶段忙碌状态、失败放弃、表单阻断、恢复后附件入请求及已有上传/表单回归。隔离生产构建通过。浏览器证据位于 output/playwright/frontend-audit/attachment-pending-browser.log；测试使用本地图标与隔离模拟接口，不写真实事件。

开发/生产、390/1440px、三个阶段共12组浏览器检查通过：每个延迟阶段按钮禁用且requestSubmit不产生POST，放行后唯一事件POST包含一个正确命名的附件。
