# 事件保存与页面生命周期（#155）

新增事件请求可能在离开页面后才完成。离开不等于撤销服务端保存；前端只停止旧页面的提示、表单重置和导航副作用，不因离页重新提交或删除记录。

`EventForm` 按登录用户隔离编辑实例，每次挂载拥有独立生命周期标识。请求成功或失败后，只有当前有效实例可以处理结果。重新进入页面得到独立表单，旧响应不能清空新的输入。成功提示的清除计时器由 effect 管理，在卸载时清理。

`AddEvent` 的两秒成功导航也由 effect 管理。保存成功后留在页面仍正常跳转到个人页；如果用户先离开，则取消该页面安排的跳转。
