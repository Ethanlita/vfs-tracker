# 窄视口大字号布局（#144）

音符频率转换工具和个人页图表在窄视口、大浏览器默认字号下保持单列收缩。表单、输入框、按钮、筛选状态和统计值允许在卡片内换行，移动端减少嵌套横向留白，避免内容宽度被多层内边距挤压。个人页图表不再用外层裁切掩盖越界内容，四个时间范围按钮及完整统计值均可在当前视口中操作和阅读。

88 键钢琴保留自身的横向滚动，因为把全部琴键压缩到窄屏会失去可用尺寸。滚动区现在是有名称的键盘焦点区域；页面本身维持视口宽度，局部钢琴区域承担必要的横向滚动。

## 验证

- 2 项大字号布局组件测试通过，覆盖转换表单收缩、输入宽度、钢琴滚动区语义、时间范围换行、全部范围可选和统计值显示。
- 完整单元测试 105 个文件/1353 项、完整集成测试 32 个文件/630 项通过。
- 生产构建与性能预算检查通过。
- 开发/生产 × 320/390/1440px × 浏览器默认字号 16/32px 共 12 组 Chromium 验收通过：两个页面的文档宽度均等于视口宽度，越界元素为零，88 键区域保持 2392px 的局部可滚动内容，四个范围按钮可通过焦点和空格键切换，转换表单可通过 Tab、空格和 Enter 操作，页面异常为零。
- 已检查生产模式 320px 转换工具与个人页，以及 390/1440px 个人页截图；表单、操作按钮、四个时间范围、图表统计和钢琴滚动区均完整可见。

## 验收边界

浏览器调试协议的默认字号覆盖不能代替 200% 页面缩放、操作系统字号、读屏软件或 iOS/Android 真机验收。脚本在每次导航后重新施加并断言根字号，防止新文档重置覆盖却产生假阳性。固定定位页头在全页截图滚动期间会出现在截图中部，这是视口滚动位置的结果；本次检查以控件边界、文档宽度和实际键盘操作判断横向裁切。
