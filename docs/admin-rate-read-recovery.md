# 管理配置读取恢复（#166）

速率限制配置首次读取失败时，不再显示 24/10 等占位数字，也不提供编辑、重置或保存入口。页面明确说明尚未取得有效配置，并提供“重试读取配置”。重试只调用 SSM 读取，不改变管理员会话；同步锁阻止连续点击产生重复请求。成功后显示服务端实际配置并清除旧错误。再次失败则继续停留在恢复状态，没有有效基线时不会发出 PutParameter。

15 项页面测试通过，覆盖首次错误、不展示输入、权限错误后恢复、重试在途锁和再次失败。隔离生产构建通过。开发/生产 × 390/1440px 四组浏览器检查均完成权限错误、网络中断、再次重试和正常保存：每组共 5 次读取（权限错误 1 次、网络错误由 SDK 尝试 3 次、恢复 1 次），恢复值为 48/3/72/5，之后正常产生 4 次配置写入。手机和桌面错误状态截图已检查。

浏览器使用虚构 AWS 凭据，STS、DynamoDB 与 SSM 请求均在本地拦截，不读取或修改真实配置。
