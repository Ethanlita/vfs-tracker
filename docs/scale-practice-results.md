# 音阶练习结果与结束行为

结果只包含检测通过轮次的边界。起始音和分析器参考最低频率不用于补齐未测结果；手动“强制通过”只推进练习，不改变已测音域。尚无通过轮次时显示“未测得”。

中途结束和下降失败后的结束共用 `handleEndPractice`，调用 `cleanupAudio` 停止音轨、关闭上下文并取消采样与轮次调度。推荐请求必须同时有有效最低和最高边界，且最低不高于最高；按钮与请求处理均检查该条件。

结果页隐藏旧麦克风电平和音色提示，显示“练习已结束，麦克风已关闭。”，避免将最后一帧电平误当成实时采集。

新增 `ScalePractice.results.test.jsx` 的8项组件测试覆盖直接结束、首轮失败、跳过、下降结束、保留已通过上行、保留完整上下界、演示不计结果与练习中离开。测量算法由独立测试覆盖；组件测试隔离检测结论以验证消费结果的流程。

音频初始化带生命周期标识：离开或清理使旧请求失效，迟到授权立即停止自己的音轨，迟到音色成功/失败不再启动采集。模块音色缓存已移除，音色仅保留在其所属的组件上下文内。初始化失败清理已获准的音轨。12项组件测试覆盖上述路径，生产构建及开发/生产迟到授权浏览器测试通过。

单拍、提示音、校准等待与耳机检测采样统一由 `createAudioTasks` 管理。清理音频时同时取消会话任务：等待返回false、采样返回null，调用方立即退出；已取消会话不能新建等待。递归轮次计时器和音高/进度动画帧继续由原有清理路径释放。

18项音阶组件测试覆盖结果来源、结束、迟到授权/音色、初始化失败及各等待阶段离开；3项任务工具测试验证正常返回、取消清理和读取异常。取消并不是暂停，用户重新进入需要新的音频会话。真机兼容性和声学准确性不在这些合成输入测试的证明范围内。

2026-09-11已验证：生产构建与现有音阶算法测试通过；开发/生产分别完成提前结束与强制跳过后结束，4条真实浏览器流程均显示上下界未测得、推荐按钮禁用，音轨ended、采集上下文closed。使用合成180Hz输入，已检查390px结果截图；不代表真实声学准确性验收。
