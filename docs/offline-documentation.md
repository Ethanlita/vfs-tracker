# 文档离线访问

生产构建将 `public/posts.json` 和 `posts/**/*.md` 加入 Service Worker 预缓存。首次联网完成应用安装后，同一版本的全部公开正文可离线访问，无需逐篇先打开。目录仍由 `npm run dev` / `prebuild` 的文档索引脚本生成。

文档通过 Rollup 资源输出到实际构建目录，避免写死 `dist` 导致隔离预览缺少正文。缺失源文件使构建失败；预缓存使用内容 revision，后续发布通过现有 PWA 更新流程切换版本。未扩展缓存到其他 JSON 或个人数据。

目录、正文和导航下拉菜单统一调用 `readDocumentation`，只有一个 fetch 路径，由 Service Worker 提供离线内容。离线且读取失败时显示“当前离线，所需文档尚未缓存。请联网后点击重试。”；联网后页面现有重试按钮重新读取。在线 HTTP 错误保留状态码与请求路径。

开发服务器不启用 Service Worker，因此断网时显示缺失提示；生产模式才提供预缓存。首次访问即断网、浏览器清除站点缓存、未完成安装时不保证离线内容。外部链接和远程图片不在此缓存范围内。

验证：`npx vitest run tests/unit/utils/documentation.test.js` 覆盖正文/目录、缓存命中、缺失提示、联网恢复和在线错误。生产构建应包含目录及全部 Markdown 的预缓存条目。浏览器验收需保留 Cache Storage、清空普通 HTTP 缓存，再断网打开目录和此前未读正文；另删除单篇缓存验证错误与联网重试。

2026-09-11本地验收：991项单元测试通过，生产预缓存95项，包含13篇正文和目录。浏览器生产模式全部正文离线读取、单篇缓存缺失恢复、开发模式断网提示与重试通过；已检查390px宽度截图。自动化重载后需重新同步网络状态再验证提示，实际物理设备断网仍待验收。
