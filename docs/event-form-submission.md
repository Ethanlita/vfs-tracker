# 事件表单提交与重试

感受记录只要求非空白正文，不要求自我测试专用的声音状态/发声方式。自我测试保留这两组校验。数字输入区分0与未填写：0和小数以数字保存，清空时删除字段，不发送空字符串。数字标签关联控件，支持辅助技术按名称定位。

正常提交和错误提示中的重试都通过同一个form提交事件；重试调用 `requestSubmit()`，重新执行浏览器必填校验和业务校验。同步锁阻止重复进入提交。API失败由 `submitAsync.error` 呈现，不再依赖被useAsync捕获后不会执行的外层catch。成功统一通知父组件并重置表单。

单元测试覆盖感受记录完整提交、空白正文、0/小数/清空、503后成功回调及修改必选项后不能绕过校验。未改变数据契约：各数值字段的业务范围、附件在途提交、日期时区和离开后的保存响应仍由其他事项处理。
