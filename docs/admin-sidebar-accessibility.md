# 管理后台移动侧栏（#117）

管理侧栏现在区分桌面常驻导航与移动模态抽屉。移动侧栏关闭时使用 `inert`、`aria-hidden` 和明确的 `tabIndex` 将隐藏导航移出辅助技术及键盘顺序；打开时提供命名的 `dialog`/`aria-modal` 语义，将焦点移到关闭按钮，并锁定背景交互和页面滚动。

抽屉支持 Escape、遮罩、关闭按钮和导航选择四种关闭路径。Tab 与 Shift+Tab 在关闭按钮和导航项之间循环；关闭后焦点回到原菜单入口。桌面断点继续使用普通导航语义，不启用模态隔离。

侧栏改为纵向弹性布局，导航区域可独立滚动，身份信息保持在底部；宽度不超过视口。移动顶部栏使用带可访问名称的紧凑图标，登出菜单限制在视口内，避免 320px 与 200% 字号下横向溢出。
