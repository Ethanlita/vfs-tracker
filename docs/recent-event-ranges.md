# 最近事件范围

事件管理与声音频率图表使用 `isInRecentDays` 作为统一范围判断入口（#143）。

- 最近 N 天包含今天，共 N 个当地日历日，起点为第 N 天之前的当地零点，终点为当前时刻，两个边界均包含。
- 列表提供 7/30/90/180 天；图表提供 7/30/90 天。标签直接显示天数，避免自然月与固定天数混用。
- `YYYY-MM-DD` 按当地日历日解释；带时区的时间戳保留瞬时时间语义。同日但晚于当前时刻的时间戳也不进入最近范围。
- “全部”保留未来记录；范围内无数据时显示空态。最近活动固定最近 30 天、最多 10 条，不再在无结果时回退到全部事件。
- 不修改存储中的日期，历史日期的解释边界见[事件日期说明](event-calendar-date.md)。
