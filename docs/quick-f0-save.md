# 快速基频测量保存（#167）

同一次测量的保存状态为“可保存→保存中→已保存”。同步引用在事件处理入口阻止重复进入，状态更新后对应按钮禁用；在线保存或离线入队成功后，按钮显示“已保存”，直到用户开始新一轮测试。

保存失败会恢复到可保存状态，保留测量结果供重试。“重新测试”会清除上次成功后的延迟跳转并重置保存状态；新测量即使频率相同也能保存。离开页面会取消已有跳转计时器，在途保存迟到成功也不再安排跳转。

刷新后的测量草稿恢复仍未解决。离线队列的账号归属和服务端重试去重见[离线队列说明](offline-events.md)。

## 有效测量与手机标题（#106）

没有通过音高范围与置信度筛选的采样时，停止测试后保留空结果并提示“未检测到有效基频”，不生成0Hz事件或显示成功测量卡片。保存按钮禁用，提交入口再次检查结果为有限正数；重新测试后有有效发声即可正常保存。无效测量不提供无意义的“重试保存”。

返回按钮与标题采用正常文档流，手机上下排列、较宽屏幕横向排列，避免绝对定位重叠。没有调整全站导航。

单元测试新增静音、低置信度、NaN、Infinity及离线静音场景，修复后全量48个文件、948项通过，生产PWA构建成功。

开发与生产的在线/离线4条浏览器路径均验证静音不可保存、重新发声可保存；320px生产页面验证标题与返回按钮不重叠。

## 快速测量的授权生命周期（#164部分）

每轮测量使用独立序号；开始、停止及卸载使旧序号失效。授权迟到成功时立即停止该请求自己的音轨，不创建分析上下文；迟到失败不显示错误或清理新测量。动画帧同样检查所属序号，避免取消后的回调操作新分析器。清理时重置分析器与音频上下文引用。

新增4项组件测试覆盖停止/卸载后授权成功，以及重启后旧授权成功/拒绝。全量48个文件、952项单元测试通过，生产PWA构建成功。浏览器使用真实合成音轨，在开发/生产、在线/离线4条路径验证迟到音轨结束、新音轨保持活动、离开页面后迟到音轨被释放，并复查静音限制、布局和保存流程。生产离线场景实际断网，未写入真实云端。

#164的Recorder组件随后已完成本地修复与自动化验收，见[录音生命周期说明](recorder-lifecycle.md)。尚未部署或完成真机权限验证。
