# 管理事件契约展示（#134）

管理员事件列表和详情现在与普通事件页面复用当前 `details` 契约。列表使用共享摘要函数：优先显示 `details.notes`，没有备注时按事件类型显示基频、训练内容、练习内容、感受正文或医生信息；列名同步改为“摘要”。管理页面不再读取已废弃的顶层 `event.note`。
