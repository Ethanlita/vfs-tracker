# 嗓音测试朗读稿件（#86）

朗读步骤使用 `/reading-passages` 作为唯一稿件来源。每篇启用稿件必须包含稳定的 `passageId`、标题 `title`、作者 `author` 和正文 `content`；缺字段、空列表和读取失败均阻止开始该步骤的录音，并提供明确的重新加载入口。

用户可以在录音前点击“换一篇”。一旦该步骤开始上传或已有录音，稿件会锁定，避免页面显示的正文与已录音内容不一致。稿件标识会随账号草稿保存；刷新或重新进入测试时会恢复录音对应的稿件并保持锁定。页面同时展示作者、正常语速说明，以及提交标题、正文、署名和授权说明的投稿入口。

## 存储与部署

CloudFormation 创建 `VoiceFemReadingPassages` 表和公开 `GET /reading-passages` Lambda。Lambda 只投影启用稿件的四个公开字段；管理后台直接使用管理员 AWS 会话对同一表执行增删改和启停。`npm run deploy:backend` 在堆栈成功后运行幂等初始化脚本，只补不存在的固定 ID，不覆盖管理员编辑。
