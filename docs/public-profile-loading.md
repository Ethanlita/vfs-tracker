# 公开资料加载与恢复

公共仪表板的用户档案将资料读取与事件明细读取分别管理（#157）。

- 打开档案后始终显示“公开资料”区域，慢请求有可访问的状态提示。
- 请求失败使用 `ApiErrorNotice` 保留原始错误及HTTP上下文，提供“重试公开资料”；不将失败解释为隐私设置。
- 重试只请求当前用户资料，不重读全局仪表板和事件明细。重试期间显示加载提示，同步锁阻止重复操作。
- 请求成功但姓名未公开时仍显示“（非公开）”，没有资料对象时显示“暂无公开资料”；这与请求失败明确区分。
- 状态带用户ID，effect失效后不能写入旧成功或旧错误；关闭、切换用户和重试都遵循同一请求路径。

`PublicDashboard.profile.test.jsx`覆盖加载/错误/重试、非公开字段对照和关闭A重试后打开B的迟到失败；现有公共明细分页测试继续覆盖迟到成功。32项相关集成测试与生产构建通过。

浏览器测试使用隔离合成账户及模拟HTTP，没有访问或修改真实资料。实体手机和屏幕阅读器仍待人工验收。

2026-09-11浏览器结果：开发390px/400、开发1440px/404、生产390px/500、生产1440px/网络失败四组均显示错误并通过键盘重试恢复姓名简介。500与网络失败经SDK自动重试后显示错误，资料请求总数为4（3次失败、1次手动恢复）；400/404为2。重试前后全局和明细请求计数不变。开发StrictMode首屏有2次读取，因此按重试前基线检查增量，不将其混同为资料重试。已查看手机错误页面截图。日志/截图位于 `output/playwright/frontend-audit/profile-load-*`。尚未提交或部署。
