# 全尺寸功能导航（#97、#98、#99）

头像在异步资料读取前使用本地生成图作为同步初值；顶栏、侧栏和账户操作区不会渲染空 `img.src`，因此页面导航不会因浏览器解析空地址而重复请求当前文档。

桌面和手机共用`SIDEBAR_ROUTES`，由顶栏最左侧的菜单图标打开同一个导航。入口不显示“全部功能”文字，通过`aria-label="打开菜单"`保留稳定的无障碍名称、对话框关联和展开状态。顶栏使用全宽布局，菜单图标不再随居中的内容容器向内偏移。移除仅含三个工具的桌面悬停菜单；补充已有添加事件、资料管理页面的入口，并合并重复仪表板链接。当前页面由NavLink标记，访客所需认证入口显示“需登录”，离线时按配置筛选并显示提示。没有添加新前端路由。

侧栏使用原生`dialog.showModal()`：关闭时不进入可聚焦顺序，打开时进入关闭按钮，背景不可交互。菜单首尾显式循环Tab；Escape、关闭按钮和遮罩均关闭菜单并恢复触发按钮焦点。导航链接点击也关闭菜单。打开时保存并锁定body滚动，退出时恢复原设置。

菜单标题固定，用户信息、功能、安装与账户操作共用`min-height:0`的纵向滚动区，高度随动态视口变化并留出底部安全区域。账户组件在侧栏采用纵向紧凑布局，避免桌面断点让按钮横向溢出。安装提示在有可用安装事件时显示，桌面和手机都可使用。

手机访客头像现在链接到登录页并保留当前路径、查询和片段作为returnUrl，不再跳转到`#`。
