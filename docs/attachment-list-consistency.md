# 附件列表与移除一致性（#160）

EventForm 使用单一附件列表同时驱动计数、展示、移除和提交。上传完成回调已经带有可用访问地址，因此表单不再针对每次列表变化重新申请所有附件链接；新增、删除不等待异步解析。渲染 key 和移除操作使用文件对象标识 fileUrl，不使用数组位置。重复移除已经不存在的文件不会影响其他附件。

下载链接仅保留在本地表单状态用于展示。构造事件请求时明确选择 fileUrl、fileType、fileName，不提交临时 downloadUrl。此操作只改变事件草稿中的关联，不物理删除上传对象。

33项表单测试通过，包含连续移除首项、新增后移除中间项、剩余附件与事件请求一致、临时字段不入请求；生产构建通过。浏览器证据保存在 output/playwright/frontend-audit/attachment-remove-browser.log。使用隔离模拟API，不代表真实后端持久化已验证。
