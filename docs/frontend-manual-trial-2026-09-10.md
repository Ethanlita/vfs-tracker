# 前端分区改进与人工试用清单

> 修复试用更新（2026-09-11）：当前工作区已完成五个批次中全部已发布问题的本地实现，并为各项补齐自动化或浏览器验收记录。完整单元回归与新增路由一致性测试合计 123 个文件/1439 项，另有 32 个集成测试文件/635 项；ESLint、生产 PWA 构建和性能预算通过。下列清单现在用于人工体验与发布后复验，最新证据见[修复验收清单](frontend-repair-acceptance-2026-09-10.md)。

> 问题发布已完成：D1—D29 对应 #146—#174，既有问题的补充评论也已发布，完整链接见[发布结果](frontend-issue-publication-results-2026-09-10.md)。本地修复尚未提交或部署，线上站点不会自动包含这些结果。

开发试用地址：http://127.0.0.1:3000/ 。运行 `npm run dev:playwright` 后会使用本地配置连接后端；登录后保存资料、事件或上传文件会发出真实请求，应使用测试账号。手机尺寸可先用浏览器设备模拟体验，这不代表真机已通过。

API 基础地址与 stage 由 `src/env.js` 统一组合；自定义域名不得重复附加 API Gateway stage。更改环境配置后必须重启开发服务器。导航、侧栏和首页入口均已在当前工作区调整，Dashboard 的用户列表仍位于末尾并按每页 20 人分页。

本清单列出已实现改动的人工验收路径。错误、慢响应和跨请求顺序问题仍需按清单模拟；正常网络下一次成功不能覆盖恢复与竞态场景。

每项可记录：`满意 / 需要改进 / 未试`，附页面、操作、屏幕宽度及期望表现。建议先体验1—4部分，再体验录音和离线流程。

## 1. 导航、侧栏与页面布局

入口：[首页](http://127.0.0.1:3000/)。关联 #97、#98、#99、#112、#144。

- [ ] 桌面：从首页寻找 dashboard、个人页、事件管理及录音工具。改进：提供清楚、稳定的功能分组和快捷入口，减少对悬停菜单的依赖。
- [ ] 手机尺寸：打开侧栏、滚到底部、进入功能再返回。改进：底部操作始终可达，菜单滚动和页面滚动协调。
- [ ] 键盘：只用 Tab、Enter、Escape 打开和关闭菜单。改进：关闭后不再进入隐藏菜单，焦点回到入口。
- [ ] 将字号放大到原来的两倍，检查表单、统计卡片及按钮。改进：文字完整，内容换行，操作不被裁掉。

## 2. 公开 dashboard 与统计

入口：[dashboard](http://127.0.0.1:3000/dashboard)。关联 #130、#131、#143，草稿 D4、D12。

- [ ] 先看统计，再滚到最后的用户列表；人数超过20时试下一页。此前已合入：用户列表最后展示，每页20人。
- [ ] 打开用户档案、关闭、切换另一个用户。改进：弹窗支持键盘操作、关闭后恢复焦点，背景不应仍可操作。
- [ ] 查看不同指标和日期范围。改进：每个指标独立判断有无数据，单位正确，有限历史范围不混入未来记录。
- [ ] 请求失败场景需另行模拟。改进：公开资料显示可重试错误，不让整个区域无解释地消失。

## 3. 登录、资料与头像

入口：[登录](http://127.0.0.1:3000/login)、[资料管理](http://127.0.0.1:3000/profile-manager)。关联 #101、#102、#113、#120—#123、#125，D6、D9、D13、D17、D25、D26。

- [ ] 从需要登录的功能进入登录页，再登录。改进：首次资料设置完成或跳过后也回到原功能。
- [ ] 编辑名称、公开选项、社交账号；在手机尺寸下添加账号。改进：按钮不超出屏幕，取消和失败时保留合理状态，页面不展示调试数据。
- [ ] 输入尚未保存的资料，再更换头像。改进：头像更新不能清掉资料草稿；刷新后的头像应与成功提示一致。
- [ ] 两个标签页分别编辑资料和头像。改进：后一次保存不覆盖另一页已经确认的字段。此项请用测试资料。
- [ ] 检查更换邮箱、修改密码、密码过期等后续流程。改进：需要验证码时提供完成入口；字段不完整不误报成功。
- [ ] 用键盘选择头像文件。改进：入口能聚焦、能激活，上传失败后可重选同一个文件。

## 4. 新增事件、历史和附件

入口：[新增事件](http://127.0.0.1:3000/add-event)、[个人页](http://127.0.0.1:3000/mypage)、[事件管理](http://127.0.0.1:3000/event-manager)。关联 #116、#126—#129、#139—#143，D3、D9、D10、D14—D16、D18。

- [ ] 切换事件类型，重点试感受记录、必填字段、数字0和默认日期。改进：字段可正常填写，所有提交及重试共用正确校验。
- [ ] 选择附件，观察上传状态和提交按钮。改进：上传未完成时不能静默遗漏附件；移除一项不会误删另一项。
- [ ] 保存等待时继续编辑或返回首页。改进：不丢后续输入，旧请求完成不把你强行带回其他页面。
- [ ] 浏览历史、搜索、筛选、翻页、查看及删除。改进：历史完整可达，摘要无 undefined，删除不重复发送，也不关闭另一条详情。
- [ ] 检查页面承诺的“编辑”是否有实际入口。改进：提供完整编辑流程，或调整与实际能力不符的说明。
- [ ] 大量历史及读取失败需专门数据/模拟。改进：翻页搜索不卡顿；失败和“没有记录”明确区分，并可重试。

## 5. 录音、快速基频与音阶

入口：[快速基频](http://127.0.0.1:3000/quick-f0-test)、[音阶练习](http://127.0.0.1:3000/scale-practice)、[完整嗓音测试](http://127.0.0.1:3000/voice-test)。关联 #106—#109，D1、D2、D19、D20、D22、D27。

- [ ] 允许/拒绝麦克风，开始、暂停、停止、离开再进入。改进：状态与计时一致，结束后系统麦克风指示消失，旧操作不影响新一轮。
- [ ] 不发声或提前结束音阶。改进：无有效测量时明确提示，不生成正常数值或未测音域。
- [ ] 完成快速测量并保存。改进：同一次成功测量只保存一次，失败仍可重试。
- [ ] 走一遍多段录音和报告流程。改进：录音与当前步骤对应，转换失败有恢复入口，刷新/离开有进度保护，报告链接失败可单独重试。

## 6. 琴键、音色与 VFS 效果预览

入口：[音符工具](http://127.0.0.1:3000/note-frequency-tool)、[效果预览](http://127.0.0.1:3000/vfs-effect-preview)。关联 #67、#137、#138，D8、D19、D20。

- [ ] 连续按琴键、切换音色、输入边界频率。改进：音名与实际频率一致，加载反馈明确，不积压后集中补播旧按键。
- [ ] 录制一段声音并比较三种算法。改进：输出音量合理，不因输入较轻而异常放大；自然度需要实际听感确认。
- [ ] 反复录制、停止、离开。改进：旧转换不打断新录音，完成后释放采集和处理资源。

## 7. PWA、离线与性能

关联 #100、#103—#105、#110、#111、#124、#145，D23、D24。

**开发服务器未启用 PWA 的 Service Worker；本地址不能用于验收安装、离线冷启动或更新缓存。该部分需要生产构建的独立试用环境。开发模式加载时间也不能当作生产性能结果。**

- [ ] 后续生产环境：先联网打开，再断网重启，进入文档和音频工具。改进：明确离线能力，已缓存功能可用，未缓存内容给出提示。
- [ ] 测试账号离线保存、恢复网络同步。改进：展示待同步记录；不串账号、不丢记录、不重复创建，存储失败可恢复。
- [ ] 两个标签页，一页编辑，另一页接受更新。改进：更新不能静默清空其他页面的草稿。
- [ ] 分别测桌面、手机慢网和大量历史。改进：减少首页无关资源加载、隐藏卡片渲染及搜索时的全量更新。

## 8. 文档与管理后台

入口：[文档列表](http://127.0.0.1:3000/posts)、[管理后台](http://127.0.0.1:3000/admin)。关联 #114、#115、#117—#119、#132—#136，D5、D7、D11、D21、D28、D29。

- [ ] 手机尺寸读长文、点目录、查看代码块。改进：目录定位正确，长词不撑宽整页，宽表和代码在自身区域滚动。
- [ ] 有管理权限时查看用户搜索、详情、最近事件和返回操作。改进：搜索覆盖所有数据；切换用户时不显示上一人的事件，旧保存不改变当前用户。
- [ ] 配置读取/保存失败需另行模拟。改进：原地重试、保留登录态，部分成功有准确反馈，旧保存不覆盖新配置。
- [ ] 改进报告上传说明，使其与实际授权访问能力一致，清楚解释谁能查看。

## 建议处理顺序

1. 数据丢失、串号、错误归属、重复提交，以及结束后仍采集。
2. 正常使用被阻塞的表单、账户验证、上传和错误恢复。
3. 导航、手机侧栏、弹窗键盘、窄屏布局和大字号。
4. 离线生命周期、性能与音频质量；与前面相关的数据保护同步处理。
