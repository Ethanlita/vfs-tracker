# 嗓音测试刷新恢复（#109）

嗓音测试向导按登录账号保存一份固定 60 分钟有效期的草稿。草稿包含服务端 `sessionId`、当前步骤、已上传文件的 `objectKey` 与文件名、三份量表答案，以及是否已经提交分析。刷新、离开后返回或 PWA 重新启动时，向导恢复同一会话，不再重复调用 `POST /sessions`。认证对象本身刷新和 React StrictMode 重放初始化 effect 也只使用一次建会话请求。

草稿使用 `voiceTestDraft:v1:<账号>` 形式的 `localStorage` 键。读取时验证版本、账号、会话、步骤、固定有效期和完整量表结构；损坏或过期记录会立即删除。不同账号只能读取自己的键，账号切换后的迟到建会话响应不能写入新账号状态。草稿不会保存已经上传录音的 Blob，因此刷新恢复后仍可继续计数和生成报告，但不能在本机重新试听已上传片段。

尚未上传的单个原始录音先写入原生 IndexedDB 数据库 `vfs-voice-test-drafts-v1`，再获取上传地址并执行 PUT。记录与账号、会话、步骤和文件名绑定，共用草稿的固定到期时间；每个账号最多保留一个片段。上传成功后删除本地原始音频，失败时显示“重试”和“放弃未上传片段”。用户必须处理或明确放弃该片段后才能继续录制，避免覆盖失败录音。浏览器拒绝持久化时不会冒充上传成功，并要求用户释放空间或放弃。

每次进入向导都会核对元数据。草稿缺失、损坏或过期时，该账号下无法归属到有效会话的 IndexedDB 录音会在创建新会话前删除；页面保持打开时，上传成功或固定期限到达都会立即删除。浏览器关闭期间不能运行定时任务，因此在关闭状态到期后的物理删除发生在下一次打开向导时，但过期记录始终不能恢复或上传。

恢复到报告步骤且 `analysisStarted` 为真时，只调用 `GET /results/{sessionId}` 续查原任务，不再次调用分析 POST。404/410 明确表示旧分析会话过期，界面只允许放弃旧进度并新建测试；其他读取错误仍可继续查询原任务。用户主动选择“放弃并新建测试”时，先清除账号的临时原始录音和草稿，再创建新会话，避免清理失败后产生无法使用的新会话。

## 生命周期与限制

- 60 分钟从服务端会话创建时开始计算，后续操作不会延长；前端期限与 S3 临时文件期限保持一致。
- 已上传文件仍由服务端生命周期策略删除；草稿到期只清理浏览器状态，不尝试删除服务端对象。
- 在途或失败的原始录音启用浏览器离页提示，并参与 PWA 更新阻止；已可靠写入草稿的服务端进度允许安全离开。
- IndexedDB 是原始录音的唯一恢复路径。存储不可用时不会引入内存或其他存储回退。

## 验证

64 项聚焦测试覆盖草稿账号隔离、Blob 排除、损坏与过期清理、量表校验、StrictMode 单次建会话、刷新恢复服务端文件、本地待上传录音重试、报告续查，以及 404/410 会话过期；完整单元测试为 96 个文件、1312 项全部通过。生产 PWA 构建生成 95 项预缓存资源。浏览器验收覆盖开发与生产模式的 390px 手机和 1440px 桌面宽度，四组均完成刷新恢复、离开后返回、IndexedDB 录音恢复与删除、报告只续查、页面内固定期限清理和单次新建会话；页面异常与控制台错误均为零。验收使用隔离 API 与合成账号，不写入真实 Cognito、S3 或分析服务。
