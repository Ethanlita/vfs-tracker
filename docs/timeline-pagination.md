# 时间轴有界渲染

InteractiveTimeline在手机与桌面只挂载一种展示布局（#139）。两端共用同一排序结果和每页10条分页状态；CSS隐藏不再留下另一套全量事件卡片。排序只在事件数据变化时重算，普通翻页不复制排序全部历史。

桌面保留横向轴线和当前页的横向滚动，翻页后从该页开头浏览。切换屏幕宽度保留页码和选中事件。桌面卡片改为原生按钮，支持键盘打开；详情接入共享ModalDialog，支持Escape、背景隔离和焦点恢复。

4项响应式组件测试及10项现有分页集成测试通过，覆盖25/250/1000条挂载上限、两端切换、详情保留和不足10条末页。生产构建通过。

后端历史读取完整性属于#116，不通过限制请求返回数量降低本次测试数据量。尚未提交或部署。

已补充按事件数据生命周期缓存访问过的日期格式化结果；不预先格式化未访问页。日期缓存前全量1089项单元测试通过，最终缓存版本14项相关测试和生产构建通过。

2026-09-11浏览器结果：两种构建分别对25/250/1000条历史做六次下一页/上一页循环，每次只挂载10个事件按钮。手机打开第二页详情后改1440px，仍显示同一事件；关闭后页码保留。桌面可翻到第100页并打开第999号样本，改回手机仍是末页且最后记录可达。使用合成记录与模拟GET，无真实事件写入。

最终单独性能实验：开发未降速1000条约7.6–12.6ms，生产4倍CPU降速1000条55.4–68.8ms，观察到的最长主线程任务71ms；原审查曾出现约1.3秒更新。方法仍为click到两次rAF及PerformanceObserver，并非INP、真实用户p75或真机结果。首次与全量测试并行的实验及最终日期缓存复测均保留：`timeline-pagination-before-date-cache.log`、`timeline-pagination-browser.log`。最终加强的桌面挂载断言测试通过，已检查桌面末页截图。
