# 录音生命周期（#164）

Recorder 和快速基频测试的每轮录音都有独立请求序号。取消授权等待或卸载页面使原请求失效：迟到成功只关闭自身音轨，迟到失败不干扰后续录音。快速测试细节见[快速基频说明](quick-f0-save.md)。

Recorder 开始时同步进入授权等待状态，禁用重复启动并显示“取消授权等待”。取消后可以重新开始；新请求不继承旧请求的资源。授权成功后进入录音状态，停止后进入处理状态，等待原生结束事件及转码完成，按钮显示“正在处理录音...”。这段处理仍属于当前录音，完成后才可以开始下一段。

每个原生录音器的回调捕获自己的音频分片和MIME类型，不再读取共享音频缓存。结束时先停止音轨、关闭采集上下文及计时器，再进行转码；转码完成前离开页面不回传旧音频。卸载会停止原生录音器并解除事件处理函数，已排队的回调也检查所属序号。

## 暂停与录音上限（#146）

录音计时使用单调时钟，按实际录制片段累计：暂停时结算当前片段并清除片段起点，恢复时创建新的起点。暂停期间计时器不更新进度、不触发自动停止。新录音与资源清理重置累计时长。显示进度不超过配置上限。

VFS预览页仍采用15秒限制，提示已从错误的“3–60秒”改为“3–15秒”，说明暂停不计时；提示和Recorder参数共用一个常量。完整嗓音向导仍使用默认60秒上限。

暂停时仅显示“录音已暂停”，不再同时显示“正在录音”。

确定性虚拟时钟测试覆盖15秒与60秒：录制、长暂停、恢复、第二次暂停、恢复达到有效录制上限。相关42项测试及全量962项单元测试通过，生产PWA构建成功。

开发和生产浏览器均使用真实MediaRecorder与合成音轨，录制约1秒后暂停16.5秒，显示保持1.0秒且原生录音器维持暂停状态；恢复后自动停止。实际生成WAV解码时长分别为14.94秒、15.06秒，与15秒上限一致（存在编码帧与200ms轮询粒度误差）。未将测试等待时间计入音频。该验证不覆盖后台标签页计时器限速或真机差异。

完整嗓音向导的开发/生产验证使用隔离会话接口，暂停期间保持0.7秒，恢复后再次暂停并放弃，不请求上传；重新录制仍采用60秒上限。最终状态提示互斥检查通过，已检查320px手机截图。该路径只验证校准步骤的录音行为，不代表整个向导已完成端到端验收。

## 转码临时上下文（#165）

Recorder使用现有`createTemporaryAudioContext`创建解码资源，在`decodeAudioData`的`finally`立即关闭，然后才进入离线重采样。外层`finally`确保异常也走同一个关闭入口；缓存关闭Promise，避免卸载与异步完成重复关闭。

组件保存当前解码资源的关闭函数，卸载时立即调用，不必等待解码完成。如果读取Blob期间已经卸载，则不再创建解码上下文；解码结束后已卸载也不继续离线重采样。关闭失败会记录错误，不能据此保证浏览器已释放资源。

新增成功、解码失败和重采样失败测试，并加强已有卸载等待测试，确认关闭只执行一次且发生在重采样前。全量49个文件、965项单元测试通过，45项Recorder相关测试通过，生产PWA构建通过。

开发/生产浏览器各完成连续三段预览录音，并测试解码失败、重采样失败及解码等待时离开，共12次资源检查通过，没有残留活动上下文或音轨。正常输出解析WAV头确认单声道、48kHz、16位，解码后样本有非零音频内容。完整嗓音向导两种模式各连续完成两段录音，仅上传至隔离拦截接口；每段完成后上下文均关闭。上述14条浏览器记录不包括实体设备长时间使用验收。

## 转换失败阻断与重试（#172）

所有原始录音都通过统一解码、单声道混合、48kHz重采样和16位PCM编码路径，不因输入自称`audio/wav`就跳过规范化。已经删除转换失败返回原始Blob的逻辑。只有转换成功才调用`onRecordingComplete`，保持向导现有`.wav`文件名和`audio/wav`上传契约。

失败时显示“录音转换失败，原录音已保留”，停止采集并关闭转换上下文。开始按钮禁用，用户可重试同一段转换或明确放弃。重试期间同步状态锁避免重复进入，成功仅回调一次；放弃不上传，并恢复重新录制。离开页面时清除内存片段，迟到成功也不回调。本次不提供刷新恢复或跨页面草稿保存。

测试新增重试成功、重试期间离开、明确放弃场景，并检查失败不回传音频。原有集成测试改用支持`arrayBuffer`的真实Blob，正常测试必须经过转换，不能靠旧回退获得成功。48项Recorder相关测试通过。

全量49个文件、968项单元测试及生产PWA构建通过。开发/生产各验证预览和向导的解码失败、重采样失败后重试，以及向导放弃失败片段，共10条浏览器路径通过。向导先成功第一段、第二段失败时仍保持1/2且不能继续；重试第二段后仅共2次上传，不重复第一段，不重新申请麦克风。实际PUT请求体具备RIFF/WAVE头，单声道、48kHz、16位且Content-Type为`audio/wav`。失败前后及重试后均检查音频上下文关闭，320px错误操作截图已检查。上传被隔离测试接口拦截，没有写入真实云端。
