# 事件删除的请求状态

`EventManager` 按事件 ID 管理删除请求（#141）。列表与详情使用同一份忙碌状态，删除中禁用对应按钮并显示“删除中…”。同步 ref 锁防止 React 重绘前的重复提交；不同事件的删除互不阻塞。

用户取消确认时不发送请求。成功通知父页面只移除对应 ID，且只有当前选择仍是被删除事件时关闭详情。用户等待期间关闭 A、打开 B，A 的迟到响应不会关闭 B。失败保留事件和详情，显示失败原因并释放锁，可以再次尝试。离开组件后迟到响应不再弹提示或调用旧页面回调；已发出的服务端删除可能完成，返回页面重新读取列表。
