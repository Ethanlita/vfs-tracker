# 管理列表筛选历史同步（#133）

事件与嗓音测试列表现在直接从 URL 读取已应用的状态、类型和搜索条件。筛选控件不再保存一份可能与地址分离的副本，因此浏览器前进或后退改变查询参数时，会自动重置分页并按恢复后的条件重新读取列表。查询变化仍沿用请求代次隔离，历史中的旧请求不能覆盖当前记录、游标或加载状态。

搜索输入框只保存尚未提交的草稿。仅切换状态或类型时会保留草稿；提交搜索后，`q` 成为已应用条件；历史导航改变 `q` 时，输入框同步恢复对应查询。这样界面明确区分“正在输入的内容”和“当前列表实际使用的内容”。

新增 2 项内存路由测试，覆盖事件状态、类型、搜索、复合条件及测试状态、搜索的返回与前进，并检查查询结果、选中控件、URL 和搜索草稿。完整单元测试为 83 个文件、1233 项，全部通过。生产构建通过。开发/生产 × 390/1440px 四组 Chromium 验收各执行 14 个 DynamoDB 查询阶段，逐项验证地址与 `status`、`type`、`q` 过滤值一致；手机和桌面截图已检查。
