# 文件选择入口和上传重试（#158、#101）

头像和附件选择入口使用原生 button，可通过正常 Tab 顺序到达，并以 Enter / 空格打开隐藏文件输入；焦点轮廓清晰。上传时保留按钮焦点，aria-disabled=true，同时阻止点击打开选择器；原生文件输入也禁用。

文件选择处理器保存明确的 File 并清空原生输入值，因此取消选择不发请求，同一个文件可以再次选择。上传与重试共用 uploadFile(File)，同步请求锁阻止并发重复上传，不再把重试按钮事件当成包含 files 的文件选择事件。附件和头像均提供失败重试入口。

25项上传组件测试及隔离生产构建通过，覆盖键盘入口、失败重试复用原文件及再次选择相同文件。相关证据保存在 output/playwright/frontend-audit/upload-entry-tests.log 与 upload-entry-browser.log。

开发3110与生产预览3111各在390/1440px完成4组浏览器检查：Tab从编辑账户到更换头像、Enter打开并取消；Tab从最后备注框到选择文件、空格打开并取消；鼠标选择真实本地图标文件，模拟PUT失败后重试成功，每组仅两次上传请求。生产手机截图确认键盘焦点轮廓。测试仅访问隔离模拟API。

测试工具注意：浏览器标签需置于前台，文件选择器采用提前注册的持续监听；临时waitForEvent方式曾超时，因此仅最终成功日志作为验证证据。备注标签尚未关联输入，测试从实际最后一个textarea开始，该标签问题未在此项中修复。
