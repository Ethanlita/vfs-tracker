# 首次资料设置后的返回目标（#162）

登录和资料设置使用 `src/routes/authReturn.js` 统一校验返回目标。仅接受已知站内页面，保留路径、查询参数和锚点；外部地址、认证页、向导自身及未知路径统一返回个人页，避免外站跳转和认证循环。

登录页等待认证与资料加载完成后，通过唯一导航 effect 决定直接返回目标或进入资料向导。认证组件的成功回调只通知 AuthContext，不在渲染阶段请求或导航。全局首次设置检查不再与登录页竞争，并将当前位置携带到向导 URL。未实际挂载在首页的 ProtectedRoute 首页重定向分支已移除。

向导完成、跳过均在保存成功后返回 URL 中的目标。失败时保留输入、步骤与目标，允许重试。刷新向导保留 URL；不使用 localStorage 等跨账户的返回目标缓存。主动进入无 returnUrl 的向导默认回个人页。未认证时访问带目标的向导，登录入口携带其有效最终目标，不将向导自身作为返回地址。本地计算工具继续豁免首次设置跳转。
