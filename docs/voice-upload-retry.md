# 嗓音向导上传归属（#107）

首次上传时固定`sessionId`、`stepId`、`fileName`和原始Blob快照。首次上传与失败重试共用`uploadRecording`：获取上传地址、上传文件、成功写入步骤列表。所有结果都使用快照中的步骤ID，不读取当前页面步骤来决定写入位置；按文件名去重，避免同一片段重复增加完成数。

同步引用阻止并行上传和重复点击。失败片段在重试或明确放弃前保留，新录音不能覆盖它；放弃仅删除本地失败快照，不改变已成功记录。已有上传不允许同时重新开始会话，离开组件或会话ID变化后的迟到结果不会写入当前列表。

失败提示仅显示在所属录音步骤，其他录音步骤显示原步骤名称和“返回该步骤处理”。上传中仍可回看其他步骤，慢请求完成后仅更新原步骤；已完成的校准步骤保持2/2，不会追加其他步骤的文件。用户可返回原步骤重试，也可明确“放弃未上传片段”后重录。

## 验证与边界

新增集成测试覆盖上传地址失败、PUT失败后跨步骤重试，重试等待时回到前一步，重复点击以及失败片段保留/放弃。35项向导集成测试通过。

生产PWA构建及全量49个文件、968项单元测试通过。首次全量运行发现管理员配置页旧测试在“保存中”断言后未等待请求完成，导致环境销毁后的未处理异常；已将100ms计时替换为显式控制的Promise并在测试退出前完成，重新运行无未处理异常。该测试修正不表示#119等管理员配置业务问题已经解决。

开发/生产浏览器分别验证上传地址失败和PUT失败，共4条路径：校准两段完成后在MPT上传失败，返回校准保持2/2且不显示其他步骤的错误操作；通过“返回该步骤处理”重试，慢上传时再次回到校准，最终2_1.wav仅进入MPT，进度1/2。每条路径获取上传地址共4次（两次校准、一次失败、一次重试）。已检查320px跨步骤提示截图。真实合成音轨经过Recorder转换，上传接口全部隔离拦截，没有云端写入。
