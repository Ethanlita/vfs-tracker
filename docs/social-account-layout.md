# 社交账号在小屏上的布局

资料管理的社交编辑行在小屏改为竖排，桌面并排。平台选择和账号输入允许缩小，不依靠隐藏横向溢出。账号展示行允许长文本在任意位置换行，同时保留删除按钮空间；公开档案中的长账号使用相同换行策略（#170）。

平台和账号输入具有独立可访问名称，可通过键盘切换到“添加”执行操作。资料标题和编辑操作允许换行，避免手机上的取消/保存文字被挤成竖排。

验证：24项资料管理/公开资料集成测试通过；生产构建通过。开发和生产分别检查320/390/1440px及16/24px根字号，编辑控件全部位于视口内，document宽度未超出视口。长中文/英文账号添加、取消无PUT、失败保留输入、重试成功、刷新一致、公开选项保存和删除持久化四组浏览器流程通过。公开档案另检查两种构建三个尺寸的200字符账号，不产生横向溢出。

使用合成账号与模拟API；未修改真实用户资料。实体手机软键盘和读屏仍待人工验收。证据位于 `output/playwright/frontend-audit/social-layout-*` 和 `social-public-*`。尚未提交或部署。
