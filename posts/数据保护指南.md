# 数据保护指南

本指南说明使用 VFS Tracker 时，哪些数据会公开、医院报告如何处理，以及您可以采取哪些保护措施。

## 公开与非公开数据

* 只有您主动设置为公开的资料和事件摘要才会进入公开页面。公开事件接口不会返回附件、完整备注或审核状态。
* 普通账户必须登录才能通过私有接口读取自己的完整事件和附件临时链接。
* 头像和您主动公开的社交账号可能对访客可见。公开前，请确认其中没有会给您造成风险的身份信息。

## 医院报告的自动处理

* 医院检测事件提交后，后端默认把报告副本发送给 Google Gemini API，与您填写的结构化数据做自动一致性比对。结果只用于事件审核，不构成医疗建议。
* Gemini Files API 的上传副本按 [Google 官方说明](https://ai.google.dev/gemini-api/docs/files) 保存 48 小时后自动删除。Google 如何处理 API 数据还受项目计费状态及其届时适用的 [Gemini API 条款](https://ai.google.dev/gemini-api/terms)约束。
* 如果您不希望 Google 处理报告，请不要上传医院报告附件。

## 谁可能访问附件

* 附件存放在非公开的 S3 存储桶中，不会直接展示在公开页面。
* 您可以通过经过身份验证的私有接口读取自己附件的限时预签名链接。
* 具有相应 AWS 权限的授权管理员或运维人员，可以通过独立的管理后台生成限时链接，用于事件审核或排查故障。
* 自动审核 Lambda 和其他获授权的后端服务会在完成对应功能时读取附件。权限控制降低了未授权访问风险，但不应理解为“任何人都不可能看到”。

## 保留与删除

* 原始附件随事件保存在 VFS Tracker 的私有 S3 存储桶中；当前没有独立于事件的固定自动到期时间。
* 删除事件时，后端先删除能够识别的关联附件，全部删除成功后再删除事件记录。附件删除失败时请求会失败，事件记录保留，您可以重试。
* 临时预签名链接会到期；链接到期不等于原始附件已删除。

## 上传前保护自己

* 上传前遮挡姓名、证件号、联系方式、住址、就诊号、条码和二维码等个人识别信息。保留判断所需的检查项目、结果、日期和设备信息即可。
* 不要在备注、文件名或公开社交账号中填写不必要的身份信息。
* 发现权限或删除异常时，请停止继续上传，并通过“联系和交流”文档中的渠道报告问题。
